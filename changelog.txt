Since 0.12.0
-----------

- Simplified decoding FieldType's
  - Removed select aliases
  - Removed Decoder::by_name
  - Renamed Decoder::by_index to Decoder::decode
  - Replaced FieldType::Decoder type with FieldType::decode method
- Added support for schemars v1 keeping support for v0.8
- Removed MySQL field from RawSQL migration operation
- Made `const_fn!` support `where` clauses
- Implemented multi-column fields (functional but experimental)
- Implemented `#[rorm(unique(field, ...))]` on models
  - It declares a unique constraint spanning several fields
    (or a multi-column field's columns) using a unique index
  - It may be repeated to declare several constraints
